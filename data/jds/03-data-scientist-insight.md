# Junior Data Scientist
Company: Insight Analytics
Location: New York, NY (On-site)
Type: Full-time, Entry-level

## About the Role
Insight Analytics is hiring a Junior Data Scientist to turn raw data into insights that guide business decisions for our clients.

## Responsibilities
- Analyse large datasets with Python, Pandas, and SQL.
- Build dashboards and data visualizations with Matplotlib, Seaborn, and Tableau.
- Apply statistics and machine learning to solve business problems.
- Present findings clearly to non-technical stakeholders.
- Write reproducible analysis code and store it in Git.

## Required Skills
- Python
- SQL
- Pandas
- NumPy
- Statistics
- Data visualization
- Machine learning
- Git

## Nice to Have
- scikit-learn
- PostgreSQL
- Power BI
- Experience with A/B testing
