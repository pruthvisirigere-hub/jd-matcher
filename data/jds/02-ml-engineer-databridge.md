# Machine Learning Engineer (Entry Level)
Company: DataBridge Inc
Location: Boston, MA (Hybrid)
Type: Full-time, Entry-level

## About the Role
DataBridge Inc is looking for an entry-level Machine Learning Engineer to help build, train, and deploy ML models that power our analytics platform.

## Responsibilities
- Train and evaluate machine learning models with scikit-learn and PyTorch.
- Prepare datasets using Pandas and NumPy, including cleaning and feature engineering.
- Deploy models as REST APIs and monitor them in production.
- Apply deep learning techniques, including Transformers, to text and tabular data.
- Write SQL queries against PostgreSQL to pull training data.
- Document experiments and model evaluation results.

## Required Skills
- Python
- Machine learning
- Deep learning
- PyTorch
- scikit-learn
- Pandas
- NumPy
- SQL
- Statistics
- Model evaluation

## Nice to Have
- TensorFlow experience
- Docker and Kubernetes
- MLOps practices and CI/CD pipelines
- AWS (SageMaker, EC2, S3)
- Apache Spark for large-scale data processing
