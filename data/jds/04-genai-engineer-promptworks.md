# Generative AI Engineer
Company: PromptWorks
Location: Remote (US)
Type: Full-time, Entry-level

## About the Role
PromptWorks builds AI assistants for customer support teams. We are hiring a Generative AI Engineer to design and improve our LLM-powered products.

## Responsibilities
- Design LLM applications with LangChain and LangGraph, including multi-step agentic workflows.
- Build RAG systems with vector databases (pgvector, Pinecone, or Weaviate).
- Engineer and test prompts; run model evaluation and evals to measure quality.
- Fine-tune or adapt open models using Transformers and PyTorch.
- Ship features behind FastAPI services and deploy with Docker.
- Stay current with large language models, prompt engineering, and NLP research.
